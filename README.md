
# More Useful Foodstuff｜更有用的食物

讓《Degrees of Lewdity》中原本只能收集的食物真正派上用場！

本模組為食物加入食用、消化、飽食度、狀態恢復、技能增益與特殊效果，並提供可自訂的食物管理介面。

玩家可以直接從食物背包中進食，透過不同食物調整角色狀態，或在一段時間內獲得技能加成。

## 主要功能

### 食物背包

- 讀取遊戲原有的食物庫存，不建立獨立物品系統。
- 依照食物類型分類，顯示物品圖示、名稱與持有數量。
- 直接點擊食物名稱即可食用，無須額外的食用按鈕。
- 點擊 `ⓘ` 查看食物效果與攝取額度。
- 點擊 `⚙` 修改單一食物設定。
- 無法食用的食物會反灰，並在資訊圖示旁顯示 `?`，供玩家查看原因。
- 食用後會扣除對應的庫存數量。

### 食用效果

不同食物可以提供以下效果：

- 恢復疲勞
- 舒緩壓力
- 增加壓力
- 緩解創傷
- 增加醉酒程度
- 增加興奮程度
- 限時技能增益
- 特殊身體轉化進度

食物的實際效果依類型及個別設定而異。

部分效果需要符合特定條件才會生效，例如身體轉化必須已經具備一定進度。

食物資訊介面會依照當前角色狀態顯示適用的效果。

### 狀態顯示

食物背包內建角色狀態區域，方便觀察進食前後的變化。

- 顯示主要狀態 Bar。
- 食用後以動畫呈現狀態變化。
- 同步更新遊戲原有的狀態顯示。
- 提供獨立的技能增益資訊頁面。
- 底部保留食用結果與提示訊息，可獨立捲動。

## 飽食與消化系統

### 攝取容量

角色具有總計 **100 點攝取容量**。

不同食物會占用不同額度，玩家不能在短時間內無限制進食。

攝取容量與飽食程度是兩個相關但不同的概念：

| 項目 | 運作方式 |
|---|---|
| 攝取容量 | 食用時占用額度，直到該筆食物消化完成才釋放 |
| 飽食程度 | 隨消化時間經過逐漸下降 |
| 食用限制 | 依照尚未釋放的攝取容量判斷 |

例如，角色吃下占用 30 點容量的食物後，即使飽食程度已逐漸下降，該筆 30 點容量仍會保留到消化完成。

這項設計用來避免玩家利用短時間連續進食反覆觸發效果。

### 消化時間

可在設定介面選擇：

| 消化時間 | 食物技能 Buff 時間 |
|---|---|
| 60 分鐘 | 30 分鐘 |
| **90 分鐘（預設）** | **45 分鐘** |
| 120 分鐘 | 60 分鐘 |
| 240 分鐘 | 120 分鐘 |
| 360 分鐘 | 180 分鐘 |

時間均以遊戲內時間計算。

每筆食用紀錄獨立計時；消化完成時，才會一次釋放該筆紀錄占用的攝取容量。

## 技能增益系統

模組提供五大類技能增益：

| 分類 | 說明 |
|---|---|
| 體能 | Physique |
| 意志 | Willpower |
| 一般技能 | General |
| 性技能 | Sexual |
| 學科技能 | Academic |

### 食物限時 Buff

食用具有技能增益的食物後，可在一定時間內提高對應技能效果。

目前規則：

- Buff 持續時間為設定消化時間的一半。
- 同一來源的 Buff 重複取得時，以延長持續時間為主。
- 不會因連續食用而無限制累加同一來源的加成強度。
- 若取得較高的加成數值，則保留較高的強度。
- 不同來源的效果依既有增益機制處理。

部分食物具有預設技能增益，例如主食、特定飲料、蘑菇與松露。

其餘食物可透過設定介面自行指派。

### 飽食階段增益

角色的飽食程度也會提供持續性的技能加成。

| 目前飽食度 | 預設體能／意志加成 |
|---|---|
| 0–24% | 無 |
| 25–49% | +5% |
| 50–74% | +10% |
| 75–100% | +15% |

飽食增益具有以下特性：

- 根據目前飽食程度即時變化。
- 不需要額外的 Buff 倒數計時。
- 飽食程度下降時，增益階段也會隨之調整。
- 可以自訂各階段的技能加成。
- 可與食物提供的限時技能 Buff 疊加。

飽食階段只適合配置持續性增益，不適合用於需要立即觸發的一次性效果。

## 特殊身體轉化

部分食物可影響角色的身體轉化進度。

目前包含與狼、哈比、貓、狐狸、牛及天使等轉化相關的食物效果。

為避免食物直接啟動原本尚未開始的轉化，系統設有額外限制：

- 對應轉化進度必須至少達到 10。
- 已達到 100 的轉化不再增加。
- 各種轉化分別檢查，不會互相影響。

食物詳情頁也會根據角色目前的轉化進度過濾顯示內容。

## 自訂食物設定

模組提供類型與單一食物兩個層級的設定。

### 類型設定

可針對整個食物分類調整預設效果。

適合用來統一管理同類食物，避免逐一修改。

### 個別食物設定

點擊食物卡片上的 `⚙`，可以修改特定食物的配置，包括：

- 食物分類
- 食用效果
- 技能增益
- 攝取容量占用量

個別設定可覆蓋類型預設值。

### 自訂標記

當設定偏離原本預設值時，介面會顯示低調的左側標記：

- 已修改的食物卡片會出現標記。
- 已修改的食物類型也會出現標記。
- 設定恢復為預設值後，標記會自動消失。

方便辨識哪些內容已經過自行調整。

## 使用方法

1. 安裝並啟用模組。
2. 進入遊戲，開啟食物背包介面。
3. 選擇食物分類。
4. 點擊食物名稱即可食用。
5. 點擊 `ⓘ` 查看效果，或使用 `⚙` 編輯設定。
6. 如果食物反灰，可點擊旁邊的 `?` 查看無法食用的原因。
7. 透過上方狀態頁面觀察角色狀態與技能增益。

食用結果會顯示在視窗底部。

## 介面設計

模組採用整合式食物管理視窗，分為三個主要區域：

**上方：角色狀態**

顯示狀態 Bar、飽食資訊及技能增益，並可切換相關分頁。

**中間：食物庫存**

依類型顯示食物卡片，提供食用、資訊查看及自訂設定。

**下方：食用結果**

顯示食用後的效果、提示與無法食用的原因。

主視窗使用響應式高度，並讓各區域獨立管理可用空間及捲動行為，以兼顧桌面與行動裝置操作。

## 設定與存檔

以下資料會隨遊戲存檔保存：

- 自訂食物設定
- 自訂類型設定
- 攝取與消化紀錄
- 技能增益相關狀態
- 消化時間設定
- 飽食階段增益設定

本模組使用遊戲原有的食物庫存，並不會另外複製或建立第二套物品數量。

## 技術說明

模組主要由以下檔案組成：

| 檔案 | 用途 |
|---|---|
| `boot.json` | 模組資訊、載入設定與相容性補丁 |
| `food-effects.js` | 食用流程、效果處理、狀態管理與 UI |
| `food-effects.css` | 介面樣式與響應式排版 |
| `FoodEffects.twee` | Twee 整合內容 |

模組透過既有的 Handler 機制處理食物效果，以便擴充不同類型的效果。

部分原版技能顯示整合使用 TweeReplacer 補丁，並透過既有技能加成入口套用增益。

## 注意事項

- 本模組會消耗角色實際持有的食物。
- 不同食物的效果可能不同，請以遊戲內資訊為準。
- 消化完成前，占用的攝取容量不會提前釋放。
- 食物技能 Buff 與飽食階段增益採用不同的持續機制。
- 修改效果設定前，建議保留遊戲存檔。
- 若與其他修改相同狀態、技能或食物資料的模組共同使用，可能需要額外相容性調整。
